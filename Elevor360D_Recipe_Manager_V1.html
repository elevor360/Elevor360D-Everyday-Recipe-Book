Publish changes

Click Download updated recipes.json, then replace the existing recipes.json file in the root of your GitHub repository. Commit the change and allow GitHub Pages to deploy. Users may need to reopen the app online to receive the latest offline cache. Personal recipes saved by users remain separate.

Recipe images are not included in this first manager; existing app photo upload for personal recipes remains unchanged. Check every recipe for accuracy, allergens, cooking temperatures and food safety before publishing.
