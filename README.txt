Elevor360D Everyday Recipe Book V1

GitHub Pages deployment:
1. Create a public GitHub repository named Elevor360D-Everyday-Recipe-Book.
2. Upload the CONTENTS of this ZIP to the repository root (not the enclosing folder).
3. Settings > Pages > Deploy from branch > main / (root).
4. Visit https://elevor360.github.io/Elevor360D-Everyday-Recipe-Book/
5. Open once while online; then install through Install App (when Chrome supplies the prompt) or the browser menu.

Advertising:
Replace advertising/adverts.json with your existing manager-generated file and copy the advert images to advertising/images/. This app reads the adverts array and supports title/image/url (also imageUrl/src/link). Relative image paths can be images/banner.jpg, or advertising/images/banner.jpg. Advert images are scaled to fit.

Note: the 200 included recipes are starter recipes composed from 100 base dish concepts with two seasoning variants. Their instructions are general cooking guidance, not independently kitchen-tested recipes. Review recipe details and food safety before publishing to customers. User recipes and notes remain on-device. For a production launch, curate and test the recipe content.
